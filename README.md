# tsunami_simulator
Tsunami simulator — the Pacific crossing, the shelf and Ofunato Bay, runup in a city, Tonga-type pressure waves and decay analysis — with a Windows window app (Japanese and English screens) — design docs and code from the book Toward a Million Lines XII / 津波のシミュレータと窓のアプリ（Windows・日英の画面）— 本『LLM で 100 万行のソフトウェア開発 XII』の設計書とコード
